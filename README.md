# 今晚吃什麼｜晚餐快選

給每天選不出晚餐的人：熟店與附近新店交替推薦，一個主推、最多兩個備選。

## 放上 GitHub Pages：不需編譯、不需金鑰

1. 建立一個新的 GitHub 儲存庫，例如 `dinner-pick`。
2. 將這個資料夾「裡面」的檔案上傳到儲存庫根目錄。最外層要直接看得到 `index.html`、`app.js`、`core.js`、`styles.css`、`services.json` 等檔案，勿再包一層資料夾。
3. 到 **Settings → Pages → Build and deployment → Source** 選 **Deploy from a branch**。
4. 選 `main` 和 `/(root)`，按 Save，等待部署完成。
5. 用 Pages 畫面顯示的網址開啟。若儲存庫名稱為 `dinner-pick`，網址通常是 `https://你的帳號.github.io/dinner-pick/`，請以 GitHub 實際顯示的網址為準。

這份專案是直接可執行的 HTML / JavaScript，沒有未編譯的 TSX。因此不用建立 Actions 工作流程。

## 第一次使用

1. 按右上角「選擇用餐地點」，輸入地區或地標；選擇搜尋結果後，就會查詢附近店家。也可由你主動授權使用目前位置。
2. 到「我的熟店」加入幾家平常常吃的店，至少填店名即可。填寫每人價格、地址及必點餐點，之後會更好用。
3. 回到「幫我選晚餐」，選預算、半徑和餐點類型，按「幫我選晚餐」。
4. 不喜歡可換一家、略過這次的類型，或暫停推薦這家。
5. 按「今天吃這家」才會新增用餐紀錄並切換下次的優先類型。新店確認吃過後會加入熟店，可再編輯或移除。

## 推薦規則與限制

- 預設新店／熟店交替；如果該類型沒有符合候選，會說明並使用另一類型。也能設定只推薦新店或只推薦熟店。
- 新店指尚未加入熟店、也沒有用餐紀錄的店，不代表剛開幕的店。
- 資料若明確標示「週一公休／星期一休息」等單日固定公休，會依台灣今天的星期排除；隔週休、節日規則和完整營業時段未做判斷，仍應向店家確認。
- 預設避開最近三天吃過的店，可調整為 0 / 1 / 3 / 7 / 14 天。
- 不會暗中放寬預算、距離或你略過的類型。若允許最近重複的店，在放寬時會顯示原因。
- 預算只能篩選有自填價格的店。OpenStreetMap 店家通常沒有價格；預設包含「價格未提供」的店，可取消勾選。
- 手動新增且沒有座標的熟店無法計算距離，仍會列入熟店候選。畫面會明確顯示「距離未提供」。
- 公開資料可能缺漏、過時或未收錄餐廳，沒有 Google 評分、即時排隊、完整的營業中篩選、完整菜單，也不會捏造這些資料。
- 公開店家查詢最多取得 150 筆，去除重複及超出半徑的店後再推薦。不是區域內所有餐廳的完整清單。
- 台灣日期依 Asia/Taipei 記錄，預算單位為新台幣。距離為直線距離，不是步行／開車里程。

## 手機與備份

- iPhone：用 Safari 開啟部署網址，透過分享選單「加入主畫面」。Android 可依瀏覽器提供的安裝／加入主畫面功能操作。
- 熟店和紀錄存在各裝置的瀏覽器，沒有跨裝置自動同步。清除網站資料或無痕視窗結束可能遺失紀錄。
- 在設定中「匯出備份」，到另一台裝置「匯入備份」。匯入採合併，保留現有資料。
- 在曾成功載入之後，離線仍可使用網站介面與已保存熟店；更新附近新店與地點搜尋需要網路。

## 資料來源、隱私與服務用量

店家：© OpenStreetMap 貢獻者（ODbL），https://www.openstreetmap.org/copyright 。店家卡片提供原始 OSM 紀錄連結。

地址搜尋由 Nominatim 提供。只在你按搜尋時查詢，不做自動完成與背景批次搜尋；地址查詢結果快取 30 天，同一裝置請求至少相隔 1.2 秒。你輸入的地區會送到 Nominatim。瀏覽器需正常傳送來源 Referer。

https://operations.osmfoundation.org/policies/nominatim/

已內建桃園區官方美食資料前 3 頁中經篩選的 19 家正餐店家（2026-11-09 整理）。排除蛋糕／伴手禮／零售商店／商圈等非正餐場所。資料來源為桃園市政府觀光旅遊局，依政府資料開放授權條款第 1 版使用，原始資料與各店家頁面均有標註。這是有限範圍的試用清單，不是完整商家名錄、也不是即時營業名單。

https://opendata.tycg.gov.tw/datalist/8dc035f1-0770-4522-8c98-96d98bb0530e

預設從內建桃園清單即時推薦，不必等待外部查詢；可更改位置。要補充其他地區或按「更新附近店家」時，由 Overpass 公開服務提供。你選定的座標及搜尋半徑會送到該服務，不會傳送熟店與用餐歷史。相同位置與半徑快取 12 小時；主動更新至少間隔 15 秒。

https://wiki.openstreetmap.org/wiki/Overpass_API

這是低流量個人用途的原型，公開服務沒有可用性保證。Nominatim 的每秒上限是整個應用合計，不是每名使用者各自享有；如果要開放多人使用，需要快取代理及全站限流，或改用自架／適用的商業服務。可修改 `services.json` 切換相容的地理編碼與 Overpass 服務，不需要改寫應用程式。

外部字型載入失敗時會使用系統字型；可刪除 `styles.css` 最上方的 Google Fonts 匯入，完全使用系統字型。

## 本機開發與檢查

使用 Node.js 22 以上：

```bash
npm test
npm run build
```

沒有第三方 JavaScript 依賴，不需要 `npm install`。`dist/` 是與根目錄相同的網站成品。若要更新內建清單，執行 `python scripts/update-taoyuan.py`；程式會從官方 API 與對應官方店家頁面取得資料，之後再執行 `npm run build`。官方頁面名稱或商家狀態變更後仍應重新檢查篩選。

若要本機預覽，使用能服務靜態檔案的 HTTP server，勿以 `file://` 雙擊，因為網站使用 ES modules。

測試涵蓋交替推薦、價格未知、預算與距離、重複用餐排除、略過類型、公開資料去重、日期與備份格式驗證。網頁上的店家資訊仍須以實際店家為準。

## 本次驗證範圍

公開地址搜尋已實際取得桃園區結果。公開 Overpass 主服務實測遇到滿載／逾時，備援節點也逾時，因此「即時更新附近店家」目前無法保證可用。為避免整個新店推薦受其影響，本版優先使用已核對官方來源並內建的桃園試用清單；其他地區的即時新店資料尚待在部署環境驗證。未驗證 iPhone 實機安裝。
